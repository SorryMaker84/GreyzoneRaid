# 灰区突围 R10

本轮让搜集物资、战斗消耗与撤离时机产生更多取舍：背包同时受件数和重量限制，医疗包改为可中断的持续治疗。R9 的射击调度、自动换弹和开箱自动搜索保留。

## 运行

- 独立程序：`Packaged_R10/Windows/GreyzoneRaid.exe`，移动时保留整个 Windows 文件夹。
- 编辑：使用 UE 5.8.3 打开 `GreyzoneRaid.uproject`，默认 Frontier 地图，点击 Play。
- 旧版：`Packaged_R9/Windows/GreyzoneRaid.exe`；修改前恢复快照：`Backups/R9_BeforeR10_Source.zip`。

## 操作与新规则

WASD 移动，鼠标转向，左键射击，右键瞄准，R 换弹，Shift 冲刺，Space 跳跃，E 开箱/长按下载情报，Tab 背包，Q 治疗或取消治疗，M 地图，Esc 关闭面板/暂停，Enter 开始/恢复/结算后重开。

- 背包最多 8 件、12 kg，两种限制都必须满足。电子组件 3 kg、医疗包 0.6 kg、弹药盒 1.2 kg、口粮 1.5 kg；未知物品搜索前不显示重量或名称。
- 此重量仅计算背包物资，不计算枪械、弹匣和已拆开的备用子弹；不是整套装备的物理负重模拟。
- 不超过 6 kg 不减速；6–12 kg 逐渐降低移动速度，最大降低 20%；达到 10 kg 无法冲刺。战斗 HUD 显示当前重量和负重状态，背包显示每件重量与容量。
- 可以在打开的容器中“放回 1”腾出容量。失败的拿取不会减少容器物品；减重后速度在下一次角色更新恢复。当前没有随地丢弃功能。
- Q 或背包中的医疗包按钮开始 3 秒治疗；开始会关闭容器/背包，停止开火和换弹。治疗中可以慢走，完成后才消耗 1 件并恢复最多 45 生命。
- 再按 Q、开火、瞄准、换弹、冲刺、跳跃、开箱/背包、受伤、失去角色控制或结束本局会取消治疗。取消不消耗医疗包、不回血。满血不消耗；重复的开始请求不重置计时。
- Esc 真正暂停时治疗计时冻结，恢复后继续；地图与容器本身不暂停战斗。治疗结束与伤害在同帧时按游戏线程实际顺序处理，不会重复消耗或重复回血。
- 弹匣空且有备弹自动换弹；持续按住开火会在换弹后续射，松开则停止。E 开箱自动逐件搜索，拿取仍需手动确认。

推荐首局：在检查站搜索医疗包与物资，注意每件价值和重量；受伤后先脱离敌人视线再治疗。拿到至少一件物资后前往南侧 S-01，停留 8 秒撤离。北侧 N-02 需要完成通讯情报任务。撤离只结算当前局，本轮没有持久仓库、出售或跨局配装。

这些重量、阈值和治疗时间均为本项目自定简化规则，不是《三角洲行动》原版数值。模块和设计说明见 `R10_CHANGE_GUIDE.md`，实际验证与未测范围见 `TEST_RESULTS_R10.md`。

本轮没有新增外部模型、纹理、音频或扩建场景。许可仍见 `ASSET_SOURCES_R7.md` 与 `ThirdPartyLicenses`。未安装组件、登录账号或修改系统音量，Git 继续暂停。
