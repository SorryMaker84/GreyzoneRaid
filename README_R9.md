# 灰区突围 R9

这是基于玩家 R8.1 试玩反馈的单人体验修订。R8.1 原包保留，旧版源文件可从 `Backups/R81_BeforeR9_Source.zip` 恢复。

## 打开与运行

- 独立游戏：`Packaged_R9/Windows/GreyzoneRaid.exe`。移动或复制时保留整个 Windows 文件夹。
- 编辑项目：使用 UE 5.8.3 打开 `GreyzoneRaid.uproject`，默认 Frontier 地图，点击 Play。
- 环境：Windows DESKTOP-TR04BB0，VS 2026 C++ 工具链、Windows SDK 10.0.22621。

## 操作规则

WASD 移动，鼠标转向，左键射击，右键按住瞄准，Shift 冲刺，Space 跳跃，R 手动换弹，E 开容器或长按下载情报，Tab 背包，Q 治疗，M 地图，Esc 关闭面板/暂停，Enter 开始/恢复/结算后重开。

- 弹匣打空且有备弹会自动换弹；空弹匣按开火也会自动换弹。没有备弹只提示，不会循环空换弹。
- 换弹后若仍按住左键，就继续射击；松开左键则不补射。换弹中按住左键也适用这条规则。R 不会重启正在进行的换弹计时。
- 瞄准在换弹时放低，若右键仍按住，完成后恢复。冲刺、打开地图、暂停会清除持续开火意图；换弹可继续，真正暂停会冻结换弹。
- 打开容器/背包会取消换弹；受伤但未死不取消换弹；死亡取消所有换弹与开火。只有完整完成一次换弹，才从备弹转入弹匣。
- E 打开有未知物品的容器，立即自动逐件搜索。已揭示物品可随时点击“拿取 1”，不必等整个容器搜完。
- 关闭、离得太远、遮挡、受伤或死亡会中断搜索。已经揭示的物品和剩余数量保留；重新打开自动从第一个未完成物品重新计时。可手动“暂停搜索/继续搜索”。
- 空容器、全部搜索完成的容器不再等待；物品不会自动进背包。地图与容器不暂停战斗，Esc 无面板时才真正暂停。

首次游玩：搜索并拿取至少 1 件物资，前往南侧 S-01，停留 8 秒撤离。北侧 N-02 需要完成通讯台地情报下载。没有跨局仓库或复杂经济。

## C++ 学习入口

- `RaidPlayer`：按键意图、下一发调度、换弹事务、命中伤害与武器表现。
- `RaidWeaponTuning`：可在角色蓝图中调整的射速、换弹时间、ADS/腰射后坐力及恢复参数。
- `RaidArmsAnimInstance`：读取同一份开火/换弹进度，评估现有手臂动画；不修改资源或骨架。
- `RaidInteractionComponent`：容器会话、自动逐件搜索和中断；`RaidInventoryComponent/Model` 保持唯一物品账本。
- `RaidHUD`、`RaidPlayerController`：中文提示、面板按钮与状态切换。
- `RaidEnemy`、`RaidExtractionZone`、`RaidGameMode`：敌人、撤离和整局流程，沿用既有规则。
